## Como publicar
Pode ser publicado no GitHub Pages, Hostinger ou qualquer hospedagem estática.
Antes da publicação final:
1. Substituir `https://SEU-DOMINIO-AQUI/` pelo domínio real em `index.html`, `robots.txt` e `sitemap.xml`.
2. Validar o domínio, SSL e canonical.
3. Revisar Política de Privacidade conforme as tecnologias realmente instaladas.
4. Conectar GA4/GTM somente com os IDs corretos.
5. Se desejar formulário próprio, conectar backend/CRM e usar `obrigado.html` como retorno de sucesso.
